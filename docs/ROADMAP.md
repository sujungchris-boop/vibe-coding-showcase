- 전시 플랫폼 전체: 갤러리·작품 상세(반응/댓글)·학생 프로필·제출·관리자

- 작품 버전 히스토리 + admin 롤백 (ADR-007) · 잘림 코드 저장 방어(confirm)
- 모바일/태블릿 최적화(제작=태블릿, 관람=폰), 아기자기 파스텔 디자인
